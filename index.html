About Humanly

Are You Human? is a real-time computer vision classifier built using MobileNetV2 Transfer Learning and FastAPI in Docker.

It distinguishes genuine human faces from non-human face-like objects (statues, digital art, anime, CGI, and masks) trained on over 8,500 labeled images.

Architecture: MobileNetV2 + GlobalAveragePooling2D + Dropout(0.2) + Sigmoid Classifier.
